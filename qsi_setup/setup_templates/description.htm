Welcome to lnxCAD Setup

lnxCAD is a standalone emergency system rescue interface for Linux, invoked instantly upon pressing Ctrl+Alt+Del.

Key Features:

  • Foolproof Ctrl+Alt+Del Rescue: Direct emergency GUI that activates even during complete desktop freezes, high CPU/RAM saturation, or GPU lockups.
  • Zero External Dependencies: Written in pure C99 using direct DRM/KMS framebuffer, completely independent of X11 or Wayland.
  • RAM-Pinned & Anti-OOM: Uses mlockall and maximum OOM score adjustment (-1000) to remain immune to swap-thrashing and memory starvation.
  • Interactive Task Manager: Inspect, sort, and selectively terminate offending processes without losing your active session.
  • Emergency ANSI Console: Built-in terminal environment to run rescue commands and repair the host system on the spot.
